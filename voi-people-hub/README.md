# Voi People Hub 💚

Hey, I’m Dania.

I built this concept because I wanted to show how People Operations can feel less admin heavy and more human. The idea is simple: one calm place where employees can ask questions, find policies, submit requests, follow onboarding and access learning.

## What is inside

* AI style People Assistant with local demo answers
* P&C service desk with working ticket creation, filters, search, updates and suggested replies
* Searchable policy library
* New starter onboarding tracker
* Internal course setup and completion view
* People analytics dashboard with working charts and recommendations
* Dark mode
* Responsive mobile layout
* Local storage, so changes stay saved in the browser

## How to run it

No setup stress.

1. Download or unzip the project
2. Open `index.html` in a browser
3. Start exploring

For the smoothest local experience, you can also run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Why I made it

The P&C Intern role at Voi talks about employee support, Jira based service requests, HR data, policy maintenance, courses, analytics and process digitalisation. I wanted to turn those responsibilities into something visual and practical.

This is a portfolio concept, not an official Voi product. The policy text and metrics are demo content only.
