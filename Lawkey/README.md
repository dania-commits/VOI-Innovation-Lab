# Lawkey 🔑

**Unlocking Nordic + UK workplace rules without the legal maze.**

Hey, I’m Dania 👋

I built Lawkey to explore a real People Operations challenge: labour law questions rarely arrive as neat legal keywords. They arrive as human situations with missing context, different jurisdictions, policies, deadlines and risk.

Lawkey turns those situations into a responsible research workflow. It helps a P&C team ask better questions, compare Nordic and UK contexts, trace possible legal changes to affected processes, and move policies through accountable review.

## What is inside

1. **Country Intelligence:** compares Sweden, Norway, Denmark, Finland and the UK without flattening their differences
2. **Change Radar:** maps a simulated legal signal to policies, templates, courses and workflows
3. **Policy Lifecycle:** tracks research, source checks, legal review, approval and publication
4. Human review guardrails, source awareness and privacy reminders throughout

## Run locally with zero setup

1. Unzip the project
2. Open the folder in VS Code
3. Open `index.html`
4. Click **Go Live**

That’s it. No installation, terminal, API key, account, build command or internet connection is required.

## Important

This is a fictional educational prototype. It does not provide legal advice, use real employee data, or replace qualified local review.
